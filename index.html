Support

Frequently asked questions

What devices are supported?

TejaBeats officially supports Android phones and tablets (Android 5.0+) and Windows desktops (Windows 10/11). iOS support is planned but not yet available.

How do I install the Android APK?

Download TejaBeats.apk using the download button above. Open it on your Android device, allow installation if asked, and tap Install.

How do I install the Windows version?

Download TejaBeats-Windows.zip using the download button above, extract it, and run TejaBeats.exe. No installer is required.

Is TejaBeats available for iPhone?

Not yet. There is no official App Store, TestFlight, or IPA download at this time. We will update this page as soon as iOS distribution is available.

How do I update TejaBeats?

Return to this page and download the latest version for your platform. The Android app also has a built-in update checker.

Where are official downloads hosted?

Official downloads are available directly from this website. Always download from tejabeats.app to avoid modified or unsafe builds.
